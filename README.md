# Digital Business Card - Exercise 1

A personal digital business card website built strictly with semantic **HTML5** and **CSS3** (zero JavaScript).

## Live Demo
- **GitHub Pages**: [https://yoav7000.github.io/exercise1/](https://yoav7000.github.io/exercise1/)
- **Repository**: [https://github.com/yoav7000/exercise1](https://github.com/yoav7000/exercise1)

## Features
- **Semantic HTML5**: Structured using semantic elements (`<header>`, `<main>`, `<section>`, `<article>`, `<address>`, `<footer>`).
- **Pure CSS Dark Mode**: Built entirely without JavaScript using CSS custom properties (variables) and the `:checked` state machine.
- **Responsive Layout**: Designed with CSS Grid and Flexbox to adapt across mobile devices, tablets, and large screens.
- **External CSS**: Fully separated styling in `style.css` without inline styles.
- **Content Sections**: Profile card, short biography, categorized technical skills, featured projects, and contact information.

## Running Locally
Open `index.html` in any modern web browser or serve via any static file server.
